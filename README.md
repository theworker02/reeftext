# reeftext

Reef validation gates for text inputs before they hit prod.

**Site:** https://theworker02.github.io/reeftext/

## Install / run

```bash
git clone https://github.com/theworker02/reeftext.git
cd reeftext
node src/cli.js
node --test
```
